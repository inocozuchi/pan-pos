# 泰山木POS 利用規約（案）

> これは**案**です。公開する前に、運営する団体で【　】の所を決め、できれば専門家に見てもらってください。

## 第1条（この規約について）
1. この規約は、【運営者の名前】（以下「運営者」）が提供する「泰山木POS」（レジ・モバイルオーダー・キッチン表示・POP作成などの機能。以下「本サービス」）の使い方を決めるものです。
2. 本サービスを使った方は、この規約に同意したものとします。

## 第2条（使える方）
1. 本サービスは、物を売るお店・団体（以下「お店」）が、自分の販売のために使えます。
2. モバイルオーダーで注文するお客様は、注文のページを使えます。

## 第3条（料金）
本サービスは無料です。ただし、通信にかかる料金は、使う方の負担です。【有料にする場合は、ここに書く】

## 第4条（お店がすること）
1. お店は、売上・在庫・商品の内容を、自分で確かめてください。本サービスの計算は、お店の帳簿・税の手続きの代わりにはなりません。
2. お店は、合流を許可する端末・オーナーにする端末を、自分で選び、管理してください。知らない端末は許可しないでください。
3. お店は、本サービスで使う写真・文字（商品の写真、POPの言葉など）が、ほかの人の権利を侵さず、法律（景品表示法など）に合っているかを確かめてください。
4. お店は、端末をなくした時に備えて、端末のロック（パスコード）を使ってください。

## 第5条（してはいけないこと）
1. ほかのお店の販売会に入ろうとすること、ほかの人の情報を見ようとすること
2. 本サービスや、本サービスが使う外のサービス（Google Firebase など）に、大量の通信を送るなど、負担をかけること
3. いたずらの注文、うその注文をすること
4. 法律や公の秩序に反すること
5. そのほか、運営者が良くないと考えること

## 第6条（データ）
1. 売上・商品などの記録は、主に使う方の端末の中に置かれます。複数の端末で共有している間は、インターネットの置き場（Google Firebase）にも置かれ、閉店すると片づけます。
2. 運営者は、端末の中の記録を見ることはできません。記録の保存（書き出し・バックアップ）は、お店が行ってください。
3. 個人情報の扱いは、プライバシーポリシーに書きます。

## 第7条（止める・変える）
1. 運営者は、点検・障害・そのほかやむを得ない時は、知らせずに本サービスを止めることがあります。
2. 運営者は、本サービスの中身を変えたり、やめたりすることがあります。

## 第8条（責任）
1. 運営者は、本サービスに不具合が無いこと、使う方の目的に合うことを約束しません。
2. 本サービスを使って起きた損害について、運営者は、運営者に故意または重大な過失がある時を除き、責任を負いません。【消費者契約法との関係を専門家に確かめる】
3. 通信の障害、外のサービス（Google Firebase・Google Fonts など）の障害で起きたことについても、同じです。

## 第9条（規約を変える）
運営者は、この規約を変えることがあります。変えた時は、本サービスの中か、【お知らせの場所】で知らせます。

## 第10条（準拠法・裁判所）
この規約は日本の法律に従います。争いになった時は、【運営者の所在地を受け持つ地方裁判所】を第一審の専属的合意管轄裁判所とします。
