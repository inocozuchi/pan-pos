# 予約帳（12月のシュトーレンの予約など）

お客様のスマホから予約を受け付ける仕組みです。**レジとは別に動きます。**
レジを初期化しても、販売会を閉じても、予約は消えません。

| ページ | だれが使う | 何をする |
| --- | --- | --- |
| `yoyaku.html?b=予約帳の印` | お客様 | 品と個数を選び、お名前と学籍番号を入れて予約する。控え（番号・QRコード）を保存する |
| `yoyaku-kanri.html` | お店 | 予約帳を作る・受付の設定・一覧・受け取り・取り消し・集計・控え・鍵 |

## 1. はじめ方

1. `yoyaku-kanri.html` を開き、「新しい予約帳を作る」を押します（12月のシュトーレンのひな形から始まります）。
2. **予約帳の鍵**が出ます。すぐに**印刷**して、大切に保管します（下の「4. 鍵」）。
3. 「受付」のタブで、題・お店の名前・受け取りの日時と場所・受付の期間・品（値段・上限）を直して「保存する」。
4. いちばん上の「受付を止めています」のスイッチを入れると、受付が始まります。
5. 「お客様のページ」のQRコード・リンクを配ります（「ポスターを印刷」もあります）。

## 2. 予約が消えないしくみ（何重にも控えを持つ）

| 置き場所 | いつ | 消えないか |
| --- | --- | --- |
| ① 置き場（Firestore の `books/…`） | 予約した時 | **だれにも消せない**決まり（`firestore.rules`）。管理者も、状態（受け取り・取り消し）を変えるだけ。変えた記録も残る |
| ② 管理の端末の中（localStorage と IndexedDB） | 一覧を開いている間、ずっと | キーの頭が `yoyakucho_` なので、**レジの初期化では消えない**。届いた予約は足すだけで、減らさない |
| ③ Google スプレッドシート（使う時だけ） | 予約が届くたび・状態が変わるたび | 「届いた記録」のシートは、届いた中身を下へ足すだけ |
| ④ 控えのファイル（JSON・CSV・印刷） | 「控えをファイルに保存」を押した時 | パソコン・USBメモリなど**別の所**に置く。新しい予約が増えると、保存するよう知らせる |
| ⑤ お客様の控え | 予約した時 | 番号・QRコード・画像で保存。お客様の端末にも、予約を覚えておく |

### 二重の予約にならない

- 予約の印（長い乱数）は、送る前にお客様の端末で作って覚えます。
- 電波が切れて「送れたか分からない」時も、**同じ印**で送り直します。置き場に同じ印があれば「届いていました」と出し、2つ目は作りません。
- 番号は、置き場の数え（`tally`）と番号の表（`seq`）を1回でいっしょに書くので、**同じ番号が2つできず、とびとびにもなりません**。
- 品ごとの上限も、同じ時に数えるので、こえて予約されません。

### 同じ学籍番号の予約

同じ学籍番号で2つ目を予約しようとすると、お客様に「すでに◯件あります」と知らせます（止めはしません）。管理の一覧には「同じ番号 2件」と出ます。学籍番号そのものは置き場に置かず、ハッシュ（元に戻せない印）だけで数えます。

## 3. 受け取りの日

- 「一覧」で、番号・お名前・学籍番号で探して「受け取り」を押します。まちがえたら、下の知らせの「元に戻す」。
- 電波が悪くても「受け取り」は押せます（電波がもどった時に送られます）。上の印が「送信待ちがあります」になります。
- 取り消しは、つながっている時だけできます（予約できる残りの数を、いっしょに戻すため）。
- 店頭・電話の予約は「＋」で足せます（受付の期間の外でも足せます）。
- 「集計」で、品ごとの予約・受け取り済み・まだの数が分かります。「受け取りの一覧を印刷」で、紙の名簿も作れます。

## 4. 予約帳の鍵

- 管理の端末をなくした・初期化した・別の端末でも管理したい時は、`yoyaku-kanri.html` の「鍵で開く」に鍵を入れます。その端末も管理者になります。
- 鍵を知っている人は、予約（お名前・学籍番号）を見られます。人に見せないでください。
- この端末が鍵を覚えていれば、管理者でなくなった時（ブラウザのデータが消えた等）も、自動で鍵を使って戻ります。

## 5. Google スプレッドシートの控え（使う時だけ）

予約が届くたびに、Google スプレッドシートにも1行ずつ写します。置き場（Firestore）が使えない時でも、ここで予約が分かります。

1. Google ドライブで、新しいスプレッドシートを作ります（例：「シュトーレン予約の控え」）。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 中の文をすべて消し、`docs/yoyakucho-sheet.gs` の中身を貼りつけて保存します。
4. 右上の **デプロイ → 新しいデプロイ** を押し、種類で **ウェブアプリ** を選びます。
   - 説明：予約帳の控え
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」を押し、Google アカウントの許可を出します。出てきた **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーします。
6. `yoyaku-kanri.html` の「受付」のタブのいちばん下に URL を貼り、「保存する」。
7. 「控え・鍵」のタブの「全部をもう一度送る」を押し、スプレッドシートに行が出るか確かめます。

- 「予約」のシート：予約1つが1行。状態が変わると、同じ行が書きかわります。
- 「届いた記録」のシート：届いた中身をそのまま下へ足します（いちばん確かな控え）。
- 送れたかどうかは、ページの側では分かりません（Google の決まり）。管理のページは、30分ごとに全部を送り直します。
- 置き場に送れない時だけ、お客様のページは「予備の受付に送る」を出します。スプレッドシートに「仮の受付（番号なし）」として入ります。お客様がもう一度ページを開くと、置き場に送り直して番号がつきます。
- URL を知っている人は、スプレッドシートに行を足せます（読むことはできません）。おかしな行があっても、置き場の予約は変わりません。

### 個人の情報

- お名前と学籍番号は、予約の受け渡しのためだけに使います（お客様のページにも書いてあります）。
- 受け取りが終わったら、スプレッドシート・控えのファイルの扱いを、お店の決まりに合わせて決めてください。置き場の予約は消せない決まりなので、残ります。

## 6. 試験

- 置き場の決まり：`tests/rules/rules.test.mjs`（「予約帳：…」）。予約は、お客様・管理者・知らない人のだれにも消せないことを確かめています。
