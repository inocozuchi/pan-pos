# POP・ポスター作成 草案

販売中の商品を押すだけで、POP（商品の札）や販売会のポスターの**下書きを自動で作り**、
好きなように直して、**画像（PNG）で保存・印刷**できるようにします。

- 設定 → レジの機能 → **「POP・ポスター」**をオンにすると、設定の「印刷」に「POP・ポスター」が出ます（初めはオフ）
- 会計には関わりません（POPを作る部品は、この画面を開いた時にだけ読み込みます）

---

## 1. 使う素材と著作権

| 素材 | 中身 | 権利 |
|---|---|---|
| テンプレート（背景・枠・模様） | プログラムで線や図形を描いて作る（9種類） | このアプリのために作った物。自由に使える |
| イラスト・飾り（花・星・桜・葉・かぼちゃ・雪・ひいらぎ・コーヒー など） | `vendor/pop.js` の中の SVG（線と図形だけで描いた物） | このアプリのために作った物。自由に使える |
| 商品の絵 | モバイルオーダーで使っている `vendor/menu-art.js` の絵 | このアプリのために作った物 |
| 商品の写真 | お店が「商品・在庫の調整」で付けた写真 | お店の物 |
| 端末の写真・画像（背景・足す写真・切り抜き） | お店が端末から読み込んだ物 | お店の物（使ってよい写真かは、お店が確かめる） |
| 文字（フォント） | Google Fonts の日本語フォント 10種類 | **SIL Open Font License 1.1**。作ったPOP・ポスター（画像・印刷物）は、商用でも自由に使える |

使うフォント（どれも SIL Open Font License 1.1）：
Zen Maru Gothic・Kiwi Maru・Mochiy Pop One・Dela Gothic One・Yusei Magic・Klee One・Shippori Mincho・Hachi Maru Pop・Yomogi・RocknRoll One

- 写真素材サイト・ほかの人のイラスト・商標（キャラクターなど）は使いません
- **AIで作った画像は使いません**。文字はすべて本物のフォントで描くので、日本語がくずれません
- フォントはインターネットから、**使う文字の分だけ**読み込みます（1回で数KB〜数十KB）。つながっていない時は、端末の文字（ヒラギノなど）で描きます

## 2. 流れ

1. **商品を選ぶ**：販売中の商品が並びます。押すと、その商品のPOPの下書きができます
   - 「販売会のポスターを作る」…日時・場所・おすすめ・メニューの一覧が入ったポスター
   - 「まとめて作る」…選んだ商品のPOPを、A4に並べて1枚にする（切って使う）
2. **下書き（自動）**：商品名・値段・写真か絵・ひとこと・札（おすすめ・新商品・人気No.1）を、テンプレートに当てはめます
   - ひとことは、商品名の言葉から選ぶ（例：「塩」→「ほどよい塩気がやみつき」）。商品に説明を入れていれば、それを使う
   - 「無添加」「国産」のような、事実かどうかアプリでは分からない言葉は、自動では入れない（スタンプから自分で選ぶ）
   - テンプレートは、分類と季節（春・秋・冬）で選ぶ。「作り直す」で別の案になる
3. **直す**：
   - 文字：書きかえ・フォント・大きさ・色・揃え・縦書き・飾り（帯・丸・吹き出し・テープ・下線）・縁取り
   - 飾り：スタンプ（おすすめ・新商品・期間限定 など）・イラスト・写真・QRコード（予約フォーム・注文ページなど）を足す。指でずらす・大きさ・向き・前後・消す
   - 指で動かす：選ぶと四すみと上に丸が出る。四すみ＝大きさ、上の丸＝向き（0°・90°・180°の近くでぴったり合う）。2本の指で広げる・ひねるでも同じ。真ん中に近づけると、真ん中に合う（点線が出る）
   - 画像（5. を見る）：端末の画像を背景にする・端末の写真を足す・背景を消して足す
   - 重なり：上にある物から並べる。かくす／出す・固定（見本で押しても選ばれない）・上へ／下へ。選んだ物は、こさ（透明度）・左右反転・複製
   - 文字の長さが変わっても重ならないように、下書きの文字（ひとこと・商品名・説明・値段）は縦に積んで並べる。指でずらした物は、その場所に置く
   - テンプレート・配色・大きさ（POP横・POP縦・名刺・A4ポスター・正方形）を切り替える（直した文字はそのまま）
   - 元に戻す
4. **保存・印刷**：画像（PNG・印刷に向く細かさ）で保存／共有、印刷（A4に並べて印刷もできる）
   - 作ったものは、この端末に残る（あとで続きから直せる）

## 4. 値段の書き方
- 消費税を「税抜きの値段」にしている時は、**税込みの値段を大きく**、本体価格を小さく出す（総額表示）
- それ以外は、登録した値段をそのまま出す

## 5. 端末の画像（背景・写真・切り抜き）

| 使い方 | しまい方 |
|---|---|
| 背景にする | 長い辺を 2480px までに小さくして JPEG |
| 写真を足す | 長い辺を 1600px までに小さくする（透ける PNG は PNG のまま、ほかは JPEG） |
| 背景を消して足す | 長い辺を 1200px までにして切り抜き、まわりの透けた所を切りとって PNG |

- しまう所：この端末の **IndexedDB**（`taizanboku_pop_img`）。localStorage（作ったPOPの記録）には、画像そのものは入れず「どの画像か」だけを書く。ほかの端末には送らない
- 「わたしの素材」に並び、ほかのPOP・ポスターでも使える。消す時は、使っているPOP・ポスターからも外す（確かめてから）
- 背景：テンプレートの背景の上に敷く。画面いっぱい／全部見せる・大きさ・位置・うすくする（白／黒）・ぼかす
- 写真：縦横の比はそのまま。角まる・まるに切りとる時は、枠の中の大きさ・位置も直せる

### 背景を消す（AIは使わない）
1. 開くと、**まわり（ふち）に多い色**を背景の色とみなし、ふちからつながっている近い色を消す（グラデーションの背景も、となりとほとんど同じ色ならたどる）
2. **タップで消す**：押した所の色と、つながった近い色を消す。「似た色の幅」を変えると、さっき消した所を新しい幅でやり直す
3. **消しゴム／戻すペン**：なぞった所を消す／戻す。ペンの太さは画面の大きさで決まる（大きく見ている時は細かく直せる）
4. 2本の指で広げる・ずらす、＋／－、全体で、見る大きさを変える。元に戻す（10回まで）・最初から
5. 「切り抜いて足す」：ふちを1つぶん内側へ寄せてから少しぼかし（背景の色が残りにくい）、まわりの透けた所を切りとって PNG でしまい、見本に足す
- 色の近さで消すので、白い台・単色の布の上で撮った写真がきれいに消える。影や、背景と同じ色の所は、消しゴム・戻すペンで直す
