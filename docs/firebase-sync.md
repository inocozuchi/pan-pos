# 複数端末リアルタイム同期（Cloud Firestore）ガイド

このアプリは、**設定を入れたときだけ**複数端末で売上をリアルタイム共有できます。
設定が空、または通信できないときは、**従来どおり各端末の中だけで安全に動作**します（オフラインでも会計は止まりません）。

---

## 1. できること
- 同じ「**共有コード**」を入れた端末どうしで、**会計・取消・修正・客属性・在庫（残数）をリアルタイム共有**。
- 2台以上で**同時に会計**しても、売上を1つのリストに統合。集計・レポートも全端末分をまとめて計算。
- 在庫は「仕入れ数 − 全端末の販売数合計」で表示（売り越しに全端末で気づける）。

## 2. 有効化の手順（コンソール作業が済んだら）
Firebaseコンソール側（プロジェクト作成／Firestore作成／匿名認証ON／`firebaseConfig`取得／ルール公開）が完了している前提です。

1. `data/firebase-config.js` を開く。
2. 末尾の `window.FIREBASE_CONFIG = null;` を、コンソールでコピーした設定に置き換える：
   ```js
   window.FIREBASE_CONFIG = {
     apiKey: "…",
     authDomain: "…",
     projectId: "…",
     storageBucket: "…",
     messagingSenderId: "…",
     appId: "…"
   };
   ```
3. GitHubにコミット＆Push（GitHub Pagesに反映）。
4. アプリを開くと「開店・設定」に **🔗 複数端末で同時に会計する** の欄が出ます。

> Web用APIキーは公開前提の識別子なので、貼り付けても問題ありません。
> データ保護は下の「セキュリティルール（匿名認証必須）」で行います。

## 3. セキュリティルール（Firestore →「ルール」に貼る）
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 販売会(events)配下は「ログイン(匿名認証)済み」のみ読み書き可
    match /events/{eventCode}/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```
- これで「未認証の直アクセス」は弾けます。
- さらに厳密にするなら、共有コードを**推測されにくい文字列**にする／後日 **App Check** を追加、を推奨します（完全会員制ではない点はご理解ください）。

## 4. 当日の使い方（2台以上で同時会計）
1. **全端末**で「開店・設定」を開く。
2. **全端末に同じ共有コード**を入力（例 `pansale-1101`）。※販売会ごとに新しいコードにしてください（前回のコードを使うと前回データが読み込まれます）。
3. 各端末で「🏪 この内容で開店する」。
4. あとは通常どおり会計。**一方の会計が数秒で他方にも反映**されます。取消・修正・客属性の入力も全端末で共有されます。
5. 閉店は各端末で行えます（リモートの記録は保持されます）。集計・レポート・CSV/PDFは全端末分をまとめて出力できます。

## 5. オフライン時の動作
- 通信が切れても会計は続行できます（端末内キャッシュに保存）。
- **回線が戻ると自動でまとめて同期**されます。
- 同期が一度も繋がらない端末は、その端末単独の売上として動きます（データは消えません）。

## 6. 客No.・在庫の注意
- 客No.は端末ごとの連番で、記録には端末ラベル（例 `DA`）が併記されます（同番号でも端末で区別可能）。
- 在庫はカート投入時点では減らず、**会計確定時**に全端末へ反映されます（複数端末では取り置き予約はできないため）。

## 7. 同期をやめたい / 1台運用に戻す
- `data/firebase-config.js` を `window.FIREBASE_CONFIG = null;` に戻してPush。
- それだけで従来の1台運用（localStorage）に戻ります。データ構造は共通なのでバックアップ/引き継ぎ機能はそのまま使えます。

## 8. 実機での確認チェックリスト（重要）
本番のFirebase接続は開発環境ではテストできないため、公開後に以下をご確認ください。
- [ ] 2台で同じコードを開き、片方の会計が数秒でもう片方に出る。
- [ ] 取消・品目修正・客属性入力が両端末に反映される。
- [ ] 在庫（残数）が両端末の販売を合算して減る。
- [ ] 1台を機内モードにして会計 → 復帰後にもう1台へ同期される。
- [ ] 閉店後の集計・レポート・CSVが全端末分の合計になっている。
