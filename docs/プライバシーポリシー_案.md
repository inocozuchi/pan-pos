# 泰山木POS プライバシーポリシー（案）

> これは**案**です。公開する前に、運営する団体で【　】の所を決め、できれば専門家に見てもらってください。

【運営者の名前】（以下「運営者」）は、「泰山木POS」（以下「本サービス」）で扱う情報を、次のように扱います。

## 1. 集める情報
本サービスは、**名前・メールアドレス・電話番号・住所などを聞きません**。扱う情報は次のとおりです。

| 情報 | どこに置くか | 何に使うか |
|---|---|---|
| 売上・商品・在庫・設定 | 使う方の端末の中。複数の端末で共有している間は、インターネットの置き場（Google Firebase）にも | レジ・集計のため |
| 端末の名前（任意で付けた名前）・端末の種類（ブラウザの情報の一部） | 共有している間、置き場に | 共有している端末の一覧に出すため |
| 匿名のログインの印（Firebase が作る、名前と結びつかない番号） | Google Firebase | 販売会に入れる端末（メンバー）を見分けるため |
| 予約のお客様の呼び名（お店が入れた時だけ） | 端末の中・共有している間は置き場に | 予約の受け渡しのため。清算・取り消しで消える |
| モバイルオーダーの注文の中身・メモ | 置き場に | お店が料理を作り、渡すため |
| 筆談で書いた文字・絵（使う時だけ） | 置き場に | お店とお客様がお話しするため。「終わる」で消える |
| 商品の写真（お店が付けた時だけ） | 端末の中・共有している間は置き場に | レジのボタン・POPなどに出すため |

## 2. 置き場（Google Firebase）について
- 本サービスは、Google LLC の Firebase（Cloud Firestore・Authentication）を使います。置き場の情報は、Google のサーバー（【日本または海外。設定したリージョン】）に置かれます。
- 置き場の情報は、その販売会のメンバーの端末だけが読めます（お客様は、メニューなどの公開用の情報と、自分の注文だけ）。
- 閉店すると、その販売会の置き場の情報を片づけ（消し）ます。

## 3. 外のサービス
- 文字（フォント）は Google Fonts から読み込みます。読み込む時に、使う方の端末の情報（IPアドレスなど）が Google に送られます。
- 天気（初めはオフ）を使う時は、Open-Meteo に地域の情報を送ります。

## 4. ほかの人に渡すこと
法律で求められた時を除き、運営者は、集めた情報をほかの人に渡しません。

## 5. 消してほしい時
- 端末の中の記録は、「設定 → データの初期化」で消せます。
- 置き場の情報は、閉店すると消えます。消えていない情報を消してほしい時は、下の窓口に連絡してください。
