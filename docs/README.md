## 泰山木POS_操作マニュアル.pdf

**このPDFは手で書き換えないでください。** アプリの中のマニュアルから書き出したものです。

本文は `index.html` の `MANUAL`（JavaScript の配列）にあります。画面名や操作を変えたときは、
そこを直せば、アプリの「設定 → 操作マニュアル」の表示とPDFの両方が同時に新しくなります。

### PDFを作り直す手順

1. アプリを開く
2. **設定 → 操作マニュアル → PDFで保存・印刷する**
3. 開いた印刷画面で「PDFとして保存」を選ぶ
4. できたファイルでこの `泰山木POS_操作マニュアル.pdf` を置き換える

配る相手がスマホ・タブレットを持っているなら、PDFを渡さずに
「設定 → 操作マニュアル」を見てもらうほうが、いつでも最新の内容になります。
