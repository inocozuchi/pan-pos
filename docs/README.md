## 泰山木POS_操作マニュアル.pdf

**このPDFは手で書き換えないでください。** アプリの中のマニュアルから書き出したものです。

本文は `index.html` の `MANUAL`（JavaScript の配列）にあります。画面名や操作を変えたときは、
そこを直せば、アプリの「設定 → 操作マニュアル」の表示とPDFの両方が同時に新しくなります。

### PDFを作り直す手順

1. アプリを開く
2. **設定 → 操作マニュアル → PDFで保存・印刷する**
3. 開いた印刷画面で「PDFとして保存」を選ぶ
4. できたファイルでこの `泰山木POS_操作マニュアル.pdf` を置き換える

配る相手がスマホ・タブレットを持っているなら、PDFを渡さずに
「設定 → 操作マニュアル」を見てもらうほうが、いつでも最新の内容になります。

## 英語の表示（i18n/en.tsv）

「設定 → 言語 / Language」で英語にした端末は、画面の文字を `i18n/en.tsv`（日本語 → 英語の辞書）で英語に置きかえて出します。
画面を作るプログラムは日本語のままで、計算や記録には関わりません。辞書に無い文は日本語のまま出ます。

- 画面に新しい文を足した時は、`i18n/en.tsv` に「日本語<TAB>英語」の行を足して、`node tools/i18n.mjs build` を実行します（`index.html` の辞書が新しくなります）。続けて `node tools/sites.mjs build`。
- `node tools/i18n.mjs check` で、`index.html` の辞書が `i18n/en.tsv` と合っているかを確かめられます。
- 会計の記録・レシート・印刷・書き出すファイル・マニュアルの本文は日本語のままです。
