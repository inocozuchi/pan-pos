# 権利と法律の確認（アプリ全体）

レジ・モバイルオーダー・キッチン表示・シンプルモード・POP・ポスターまで、アプリ全体で
「法律や他人の権利にふれる所がないか」を確かめた記録です。

> **大事なこと**：これは、アプリを作る側で確かめられる範囲の確認です。弁護士・税理士などの
> 専門家の判断ではありません。「どんな場合でも問題が起きない」と言い切ることはできません。
> とくに下の **「お店で対応が要る」** の所は、運営する団体で確かめてください。

- 確かめた日：2026年10月10日
- 印の意味：**問題なし**／**直した**（この確認で直した）／**お店で対応が要る**

## 2. 商標
| 物 | 結果 |
|---|---|
| 「QRコード」（株式会社デンソーウェーブの登録商標） | **直した**：マニュアルの「権利・ライセンス」に商標であることを書いた。QRコードそのものは自由に使える |
| 支払い方法の名前（PayPay・楽天ペイ・au PAY・d払い など） | 「どの方法で払ったか」を記録するための文字だけ。ロゴは使っていない。問題なし |
| Google Fonts・Firebase・Open-Meteo などの名前 | 出どころを示すための文字だけ。問題なし |

## 3. 表示（景品表示法・食品の表示）
| 物 | 結果 |
|---|---|
| 「人気No.1」の自動の札 | **直した**：「当店人気No.1」にし、根拠（当店の販売数と、その期間）を下に小さく自動で入れる。No.1 は、何と比べたか・いつの数かを、すぐそばに書く必要があるため |
| スタンプの「人気No.1」「無添加」 | **直した**：スタンプから外した。「無添加」は、何を使っていないのかを具体的に書く必要がある（食品添加物の不使用表示のガイドライン） |
| 「新商品」「期間限定」「焼きたて」「手作り」 | 本当にそうな時だけ使う。「新商品」は売り始めてから長くても半年くらいまで。**お店で対応が要る**（画面とマニュアルに書いた） |
| 自動のひとこと | 好みの言葉だけで、中身を言い切る言葉は使わない。焼いたりんごに合わない「シャキッと」を**直した** |
| 値段の表示 | 税込みで出す（税抜きにしている時は、税込みを大きく）。**直した**：POPの値段が登録の値段と違う時に知らせる・ポスターのメニューやまとめて作る時は、いまの値段に合わせる |
| 食品の表示（原材料・アレルギーなど） | その場で作って、その場で売る物は、表示の義務が無いことが多い。ただ、アレルギーを聞かれた時に答えられるようにしておくのが安心。**お店で確かめる** |

## 4. お金・税
| 物 | 結果 |
|---|---|
| インボイス（適格簡易請求書） | 登録番号は、登録している時だけ印字。税率ごとの合計と消費税、軽減税率の印（※）を出す。問題なし |
| 収入印紙（5万円以上の紙の領収書） | **直した**：領収書の画面に「収入印紙が要る場合がある」と知らせる（印刷はされない）。会社が運営する所は要り、社会福祉法人・NPO法人などの「営業に関しない受取書」は要らない。**どちらになるかは、お店で確かめる** |
| 帳簿の保存 | このアプリの記録は、お店の帳簿をつける助けです。帳簿や書類の保存の決まりは、運営する団体で守る |

## 5. 個人情報
| 物 | 結果 |
|---|---|
| モバイルオーダー | 名前・電話番号などは聞かない（注文の中身と、ひとことのメモだけ）。問題なし |
| 予約のお客様の名前 | **直した**：名前を聞く時に「名字だけ・呼び名でかまいません。電話番号などは入れません」と出す |
| 複数の端末で共有している時の置き場（Firebase） | 予約の名前も置き場に置かれ、清算・取り消しで消える。**お店で対応が要る**：共有コードは4けたで、いまのルール（ログインしていれば読み書きできる）のままだと、ほかの人がのぞける心配が残る。`docs/firebase-sync.md` の「厳しいルール」に切り替えてください |
| サンプルの商品名 | `data/products.normal.js` に、作った人の呼び名が入った商品名（「○○ちゃんの…クッキー」）がある。リポジトリは公開されているので、**お店で対応が要る**：本人（と必要なら家族）の了解を取るか、呼び名を外してください。障害のある人の作業所であることと結びつくと、とくに気をつける情報になります |
| 端末の中の記録 | 売上・設定などは端末の中（ブラウザ）に置く。端末をなくした時に備えて、端末のロック（パスコード）を使ってください |

## まとめ：お店でしてほしいこと
1. **Firebase のルール**を `docs/firebase-sync.md` の「厳しいルール」にする（予約の名前を守るため）
2. **サンプルの商品名の呼び名**：本人の了解を取るか、外す
3. **収入印紙**：運営する団体が、5万円以上の領収書に印紙が要る団体かを確かめる
4. **天気**：お店の営業で使うなら、Open-Meteo の条件を確かめる（オフのままなら不要）
5. **写真・POPの言葉**：使ってよい写真だけ、本当のことだけを書く（マニュアル「権利・ライセンス」）
6. ほかの施設にも使ってもらう時は、このアプリの利用許諾（LICENSE）を決める
