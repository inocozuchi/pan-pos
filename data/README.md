# 商品データ（イベント別ラインナップ）

レジに表示する商品は、この `data/` フォルダのファイルで管理します。
**コード本体（`index.html`）を編集せずに**、商品や価格、イベントの切り替えができます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `products.normal.js`   | **通常販売（学内）** の商品ラインナップ |
| `products.festival.js` | **お祭り出店** の商品ラインナップ（例） |
| `active-event.js`      | **どのイベントを表示するかの切り替え設定（ここ1行だけ変更）** |
| `taste-master.js`      | 味タグ（甘い系/しょっぱい系/ドリンク）の自動判定キーワード辞書 |

> なぜ JSON ではなく `.js`？ … このアプリはビルド無しの静的サイトで、ファイルを直接開いた
> 状態（`file://`）でも動く必要があります。JSON を `fetch` するとローカルでは読み込めない
> ため、`<script>` で確実に読める JS ファイル形式にしています。

## イベントの切り替え方（3通り・どれか1つ）

1. **設定ファイルを1行変更（本番はこれ）**
   `active-event.js` を開き、次の行を書き換えて保存 → GitHub にコミット/デプロイ。
   ```js
   window.ACTIVE_EVENT = "normal";     // 通常販売
   // window.ACTIVE_EVENT = "festival"; // お祭り
   ```
2. **URL で一時切り替え（確認用・ファイルを変えない）**
   例: `.../index.html?event=festival`
3. **端末で切り替え（すでにデータが入っている端末）**
   設定 → 営業管理 →「↩️ 商品リストを『◯◯』の既定に戻す」を1タップ →（仕入れ数を調整して）開店。
   ※初回（データ未保存）の端末は、①②の変更が自動で反映されます。

## 商品の書き方

`products.*.js` の `items` に、商品を1行ずつ書きます。

```js
{ name: "あんぱん", price: 180, category: "パン" }
```

| キー | 必須 | 説明 |
|---|---|---|
| `name`     | ○ | 商品名（レシート・CSV にもこの名前で出ます） |
| `price`    | ○ | 価格（円） |
| `category` | ○ | `"パン"` / `"クッキー"` / `"ドリンク"` のいずれか（表示色の3グループ） |
| `stock`    | – | 既定の仕入れ数（省略時 50）。開店時に当日の実数へ調整できます |
| `cost`     | – | 原価（円・任意）。入力すると集計結果に粗利・粗利率が表示されます |
| `taste`    | – | 味タグの明示指定（任意）。`"甘い系"` / `"しょっぱい系"` / `"ドリンク"`。省略時は商品名から自動推定 |

- 味の傾向（甘い/しょっぱい）は商品名から自動推定されるので、通常は指定不要です。
  自動判定が合わないときだけ `taste` で上書きできます（例: `{ name:"謎のパン", price:200, category:"パン", taste:"しょっぱい系" }`）。
- 自動判定に使うキーワード辞書は `data/taste-master.js`（`window.TASTE_MASTER`）で管理します。
  よく出す商品でうまく分類されない語があれば、この辞書に追記してください。
- `cost` は開店画面の「原価（任意）」欄でも入力・変更できます（未入力の商品は粗利計算から除外）。
- 価格 0・在庫 0 にすると「準備中（販売不可）」の枠になります（将来の商品の場所取りに）。

## 新しいイベントを追加する手順（例：バザー）

1. `data/products.bazaar.js` を新規作成し、中身をコピーして編集:
   ```js
   window.PRODUCT_SETS = window.PRODUCT_SETS || {};
   window.PRODUCT_SETS.bazaar = {
     label: "バザー",
     items: [
       { name: "サンプル商品A", price: 100, category: "パン" },
       { name: "サンプル商品B", price: 200, category: "クッキー" }
     ]
   };
   ```
2. `index.html` の下部に読み込みタグを1行追加（他のデータ行の隣）:
   ```html
   <script src="data/products.bazaar.js"></script>
   ```
3. 使うときは `active-event.js` を `window.ACTIVE_EVENT = "bazaar";` に変更。
   （`?event=bazaar` でも確認できます）
